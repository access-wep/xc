# منصة فكرتو (Fekrto) - Professional SaaS Task & Time Management Platform

منصة ويب متكاملة وحديثة لتنظيم الوقت وإدارة المهام الشخصية والمهنية، مبنية وفق أعلى معايير منتجات الـ SaaS العالمية مع دعم أصيل للغة العربية (RTL) والوضع الليلي/النهاري، ونظام اشتراكات ومدفوعات يدوية ولوحة تحكم مركزية للإدارة.

---

## 🚀 التقنيات المستخدمة (Tech Stack)

- **Framework:** Next.js 14 (App Router)
- **UI & Frontend:** React 18, Tailwind CSS, Lucide Icons
- **Language:** TypeScript (Strict Type Safety)
- **Database & Auth:** Supabase (PostgreSQL, Row Level Security, Auth, Storage)
- **Hosting & Deployment:** Cloudflare Pages
- **Design Intelligence:** مبني ومصمم وفق معايير `ui-ux-pro-max-skill` (Contrast, Spacing, Micro-interactions, Logical RTL Properties)

## ✨ المميزات الرئيسية للمنصة

### 1. نظام الحسابات والأمان (Authentication & Security)
- تسجيل حساب جديد باشتراط بلوغ السن القانوني (18 عامًا فما فوق) والتحقق منه برمجياً وقاعدة بيانات.
- تسجيل الدخول بالبريد الإلكتروني أو حساب Google عبر OAuth.
- استعادة وتعيين كلمة المرور.
- حماية الجلسات وصلاحيات الوصول على مستوى السيرفر وقاعدة البيانات بواسطة Supabase RLS.

### 2. لوحة تحكم المستخدم (User Dashboard)
- رسالة ترحيبية ذكية باسم المستخدم.
- ملخص المهام اليومية (إجمالي، مكتملة، متبقية، نسبة الإنجاز).
- شريط تقدم ذكي ومؤشر استمرارية وإنجاز تفاعلي (Streak Counter 🔥).
- تقويم تفاعلي مع إمكانية التبديل بين الأيام ومتابعة المهام السابقة والقادمة.
- إمكانية تعليم إنجاز المهام فورًا مع إعادة حساب الإحصائيات لحظيًا.

### 3. نظام الجداول وإدارة الوقت (Schedules System)
- إنشاء جداول مرنة متعددة ومستقلة:
  - جدول يومي (Daily)
  - جدول أسبوعي (Weekly)
  - جدول شهري (Monthly)
  - جدول سنوي (Yearly)
  - فترة مخصصة (Custom Date Range)
- توليد الأيام تلقائيًا بحسب الفترة المحددة.
- إمكانية نسخ ومضاعفة (Duplicate / Clone) أي جدول سابق بمهامه وتفاصيله.
- تعديل وحذف وإدارة الجداول بسهولة تامة.

### 4. الجدول اليومي التفصيلي (Detailed Daily Planner)
- واجهة تقسيم شاشة تعرض قائمة الأيام والتفاصيل اليومية جنبًا إلى جنب.
- إضافة عدد غير محدود من المهام لكل يوم.
- تفاصيل المهمة: العنوان، الوصف، وقت البداية، وقت النهاية، المدة بالدقائق، الأولوية (منخفضة، متوسطة، عالية، عاجلة)، الحالة (لم تبدأ، قيد التنفيذ، مكتملة، مؤجلة، ملغاة)، وملاحظات إضافية.
- ربط دقيق بالتاريخ والجدول الخاص بالمهمة.

### 5. قواعد احتساب الإنجاز الصارمة (Strict Completion Rules)
- لا يُحتسب اليوم مكتملًا إلا عند إنجاز 100% من المهام المطلوبة لذلك اليوم.
- الأيام المستقبلية لا تُحسب كأيام فاشلة مطلقًا.
- المهام الملغاة تُستبعد تلقائيًا من الحساب دون التأثير سلبًا على معدلك.
- عند إضافة مهمة جديدة ليوم تم اكتماله مسبقًا، يُعاد تقييم نسبة اليوم فورًا.
- عند حذف مهمة يُعاد احتساب المعدل الأسبوعي والشهري بدقة.

### 6. نظام الاشتراكات والدفع اليدوي (Manual Payment & Subscriptions)
- خطط أسعار مرنة (اشتراك شهري وسنوي مع خصم 40%).
- نظام كوبونات وأكواد خصم ذكي يحسب الخصومات فورًا (نسبة مئوية أو قيمة ثابتة).
- دعم طرق دفع بنكية ومحافظ رقمية متعددة (تحويل بنك الراجحي، STC Pay، محافظ رقمية).
- دورة الدفع اليدوي:
  1. يختار المشترك الباقة وطريقة التحويل ويحصل على بيانات الحساب والآيبان.
  2. يرفع صورة إيصال التحويل البنكي أو لقطة الشاشة.
  3. يتم إنشاء طلب دفع بحالة معلقة (Pending).
  4. يراجع الأدمن الإيصال ويعتمد الطلب أو يرفضه مع إبداء السبب.
  5. عند القبول، يتم تفعيل الاشتراك فورياً وحساب مدة الانتهاء بدقة.

### 7. لوحة تحكم الإدارة المركزية (Admin Dashboard)
- واجهة منفصلة ومحمية بمسار `/admin` مع تحقق صارم من الصلاحيات.
- **إدارة المدفوعات:** فحص صور الإيصالات، قبول الدفعات وتفعيل الاشتراكات تلقائيًا، أو رفضها وتوضيح السبب.
- **إدارة المستخدمين:** بحث متقدم، تدقيق الأعمار وتاريخ التسجيل، وتفعيل أو إيقاف الحسابات.
- **إدارة الأسعار والكوبونات:** تعديل السعر الشهري والسنوي فورياً، وإنشاء وإلغاء كوبونات الخصم.
- **إدارة طرق الدفع:** إضافة بنوك ومحافظ جديدة وتعديل أرقام الحسابات والتعليمات.
- **إدارة الصفحات القانونية:** تعديل نصوص شروط الاستخدام، سياسة الخصوصية، الاسترداد، والأسئلة الشائعة من داخل لوحة التحكم مباشرة.

## 🛠️ إعداد المشروع وتشغيله محليًا (Local Setup)

### 1. المتطلبات
- Node.js 18 فما فوق
- npm

### 2. تثبيت الحزم
\`\`\`bash
npm install
\`\`\`

### 3. إعداد متغيرات البيئة
قم بإنشاء ملف `.env.local` بناءً على النموذج في `.env.example`:
\`\`\`env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
NEXT_PUBLIC_APP_URL=http://localhost:3000
\`\`\`

### 4. تطبيق قاعدة بيانات Supabase
قم بتشغيل ملفات الـ SQL الموجودة في مجلد `supabase/migrations/` بالترتيب داخل Supabase SQL Editor:
1. `supabase/migrations/01_initial_schema.sql` (الجداول، العلاقات، وسياسات RLS، والدوال المحفزة)
2. `supabase/migrations/02_seed_data.sql` (البيانات الأولية للباقات، طرق الدفع، الصفحات القانونية، والكوبونات)

### 5. تشغيل بيئة التطوير
\`\`\`bash
npm run dev
\`\`\`
افتح المتصفح على: [http://localhost:3000](http://localhost:3000)

### 6. التحقق من البناء والإنتاج
\`\`\`bash
npm run build
\`\`\`

## ☁️ النشر على Cloudflare Pages

تم تجهيز المشروع للنشر المباشر عبر Cloudflare Pages:
1. اربط المستودع في Cloudflare Pages dashboard.
2. اختر إعدادات البناء:
   - **Framework Preset:** Next.js
   - **Build Command:** `npm run build`
   - **Build Output Directory:** `.next`
3. أضف متغيرات البيئة (`NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY`) في لوحة إعدادات Cloudflare.
